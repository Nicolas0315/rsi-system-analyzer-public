# Code of Conduct

We are committed to a respectful, harassment-free project.

Be constructive, assume good intent, accept correction, and focus criticism on
the work. Harassment, discrimination, threats, doxxing, credential exposure,
and publication of another person's machine data are not acceptable.

Project maintainers may edit or remove contributions and restrict participation
when behavior threatens people, privacy, or the project. Report conduct issues
privately through the repository owner rather than in a public issue.
